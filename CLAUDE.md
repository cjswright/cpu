# Purpose

This is a learning project. The author writes the code to learn CPU
design and SystemVerilog.

# Rules for AI assistants

Do not change any file unless the user directly asks for that change.
This includes source, tests, build scripts, lint and editor config.

Otherwise, only explain. Answer questions, point out problems and
suggest fixes in prose or short snippets, and leave the edits to the
user.

If a change seems useful, describe it and ask. Do not apply it.
